# Course longue distance — site

Сайт-презентация спектакля «Course longue distance / Бег на длинную дистанцию».
100 км → потом спектакль по Мураками, без паузы.

**Премьера:** 13 марта 2026, Le Chat Noir, Париж.
**Следующий показ:** **20 июня 2026 — Ultramarathon en soutien aux réfugiés**.

## Структура

```
course-longue-distance-site/
├── index.html              # один файл, всё внутри (CSS + JS)
└── assets/
    ├── poster.jpg          # красный плакат COURSE LONGUE DISTANCE
    ├── photo-1.jpg…4.jpg   # ч/б фото с забега 13.03 (Dima Chyornyy)
    ├── handwriting-refugees.png  # ОПЦИОНАЛЬНО — твой рукописный заголовок
    └── sketch-runner.png         # ОПЦИОНАЛЬНО — твой эскиз бегуна
```

## Открыть локально

```
open ~/Desktop/course-longue-distance-site/index.html
```

## Дизайн-решения

- **Палитра:** чёрный, бумажный (#F4F1EC), кроваво-красный (#E10600) — в тон плакату.
- **Шрифт:** Archivo Black (плакатный, как на афише) + Inter (тело) + Permanent Marker / Caveat (рука).
- **Зерно** — фиксированный SVG-noise overlay 18% multiply, дышит каждые 1.2s.
- **Поэтика бега:**
  - пульсирующая красная точка в навбаре (1.05s — твой темп);
  - постер на героике медленно «дышит» (zoom 1.02 → 1.06);
  - КМ-счётчик справа сверху, привязанный к скроллу страницы (0 → 100 км);
  - бесконечная плёнка ч/б фото с белой рамкой и красной тенью.
- **Секция 20 июня** — красная плита, твой рукописный заголовок (или SVG-«близнец»), большая дата `20.06.2026`, манифест беженцев, эскиз бегуна, 4 CTA-кнопки (прийти / Instagram / дать телефон / позвать на фестиваль).

## Заменить SVG-fallback на свои рукописные

В `assets/` положи два PNG с прозрачным фоном:
1. `handwriting-refugees.png` — твой «Ultramarathon en soutien aux RÉFUGIÉS» (изображение с подчёркиванием).
2. `sketch-runner.png` — эскиз бегущего человечка с линиями ветра.

Сайт автоматически возьмёт их вместо встроенных SVG-имитаций (через `<picture><source>`).
